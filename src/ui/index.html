    Warm and cold context
    Fixed rules, no AI: reads and edits, halved every three days. Threads start with the warm files; cold files stay attached and are opened only when needed.
    Freeze per thread
    Fixed rules, no AI: files a thread used earlier but not in its last 10 minutes or 2 messages. Each message tells the thread to skip them unless needed. Nothing is blocked; a file unfreezes when used. Click a thread to see its frozen files.
    Auto-calibrate
    Fixed rules, no AI. Once a thread passes amber, and again at red, WEAVE tells it in one line to suggest a new thread on the smallest preset that fits its work, saving one from its warm files if none does.
    Context warnings
    Fixed rules, no AI. A thread turns amber, then red, and WEAVE suggests a new thread with a start line for the saved preset that best fits its work.
    When Claude asks for a detached file
    Follow system motion
    Pause signals and embers when your device asks apps to reduce motion.
    Exact token counts

    With a key, each file's text is sent to Anthropic's free token-counting service and counted once until it changes. The key is stored in a private file in your user folder, never in the project, and this page cannot read it back. Without a key everything stays on this computer.
