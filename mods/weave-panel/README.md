# weave-panel

A Claude Code mod. While Claude works, a small box sits above the prompt, under Claude's text, as wide as the chat. It shows what Claude is touching right now in WEAVE's Live view style: a folder row, a dashed connector, and a node row with a pastel accent bar, the file name, a status and a dot. A working node shows the same thinking orbs as the WEAVE map (Read is searching, Edit is composing, Run is working, PR is weaving), in the map's colours. On the terminal the orb is a small spinner glyph.

The button at the top right grows the same box in place to the folder and heat view: every folder touched this session, each file tinted from cool blue to rose by how often it was touched, with a count.

Fixed rules only, no AI: a tool call becomes a folder and a file from its path (the first two folders under the project), `Bash` is a Shell node under the project, and `gh pr` or `git push` is a PR node.

## Try it

From a checkout of WEAVE:

```bash
claude --plugin-dir mods/weave-panel
```

Or set `CLAUDE_CODE_PLUGIN_DIRS` to the `mods/weave-panel` folder, and start Claude Code (the terminal or the desktop app) as usual. Ask Claude to read or edit a file and the box appears under its text.

## Files

- `hooks/register.tsx`: the mod.
- `hooks/orbs.ts`: the orb frames, generated by `scripts/gen-orbs.mjs` from the thinking-orbs engine (MIT, see THIRD_PARTY_NOTICES.md). Re-run `node scripts/gen-orbs.mjs` to rebuild it.
- `weave-panel.test.tsx`: `claude plugin test mods/weave-panel`.
